Renaissance Press — static site (Markdown + bslib)

A static rebuild of renaissancepress.co.uk (the Edinburgh poetry-and-art publisher), reconciled against the WordPress export renaissancepress_WordPress_2026-07-18.xml. Every page is plain Markdown; the theme, fonts and Bootstrap styling are supplied by bslib (Bootstrap 5) and reproduce the site’s WordPress “Twenty Sixteen” theme including its Customizer overrides.

Build it

install.packages(c("rmarkdown", "bslib", "sass"))
rmarkdown::render_site(encoding = "UTF-8")   # or: Rscript build.R

Output lands in ./_site. Deploy that folder to any static host.

Please check before publishing

  1. Images are referenced from the live renaissancepress.co.uk/wp-content/… URLs (from the export). For a fully self-contained site, download the 52 attachments into an assets/ folder and repoint the <img src>/![]() paths.
  2. A stale phone number (0131 556 3118) is embedded in the Woman of the North Sea and The Sacred Sea product descriptions — this is your original copy, left verbatim. Update it to the Milngavie number if you wish.
  3. Cart/checkout are omitted (this is static); product pages link to “Order or enquire” → Contact, matching the portfolios’ existing guidance. For a live basket, a commerce backend (e.g. Snipcart) can be added.
  4. Customer orders (107 shop_order records in the export) were deliberately not used — they contain personal data and don’t belong on a public site.
  5. Nav matches the live primary menu (Home · Books · Prints · Folios · Contact). Artists & Authors and the memorial are reached from the home page and footer, as on the live site.
